# 文档体检器

**输入**一个 Markdown 文件夹路径，**输出**一份问题清单（Markdown 表格 + JSON）。

## 解决什么问题

写文档时最容易漏掉的是"引用了不存在的文件"和"标题层级跳级"。
人工检查要很久，而且会漏。

## 使用场景

- 交付前自查
- 代码评审前跑一遍

## 环境要求

Python ≥ 3.9，零依赖，不需要 pip install。

## 使用步骤

1. 把待检查的文件夹放到任意位置
2. 运行 `python scripts/doc_check.py <文件夹路径>`
3. 看输出的问题清单

## 示例

输入：
```
docs/
├── a.md   （里面引用了 ./missing.png）
```

输出：
```
| 文件 | 问题 | 位置 |
|---|---|---|
| a.md | 引用了不存在的文件 | 第 12 行 |
```

## 不适用的情况

只适用于 Markdown。Word/PDF 不在范围内。
